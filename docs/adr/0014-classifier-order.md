# 終局分類順序：提淨、Benson、雙活、劫、停後剩餘當死、做不成活則死

對目標棋串依序判定：(1) 目標子都不在盤上 → 無條件死；(2) Benson → 無條件活；(3) 雙活（ADR-0010）；(4) 贏劫／輸劫两次假設（ADR-0009）；(5) 雙方已停且以上皆非 → 無條件死；(6) 目標只剩一色，該色就算連續落子、對方脫先也到不了 Benson → 無條件死；(7) 否則未定。殺棋不能要求一定收到碗裡。第 (6) 步讓封死的假眼／單眼在雙方還繼續下之前就結束；否則搜尋把填氣當成抵抗，證明深度被灌水。應手另依 ADR-0011：先比黑能強迫的著手數，故 small_trick 黑 S19 後是 R19 而不是連回的 S18。眼位連通空點太多則當未定，避免把還能跑的棋誤殺。已提掉一部分目標、剩下的已 Benson 活，不算第 (6) 步——殺棋多串仍是 AND。
