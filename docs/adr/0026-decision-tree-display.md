# 盤右是決策樹：分組、同列改寫、黑勝／白勝；搜尋仍報每一條搜尋路徑

不限時與「每走到終局報一條搜尋路徑」仍依 ADR-0019。殼不再把那些字串平鋪編號。右邊欄標題是決策樹：白第一手、黑第二手列出出現過的所有，第三步起每個（白、黑）只露出該白節點最長抵抗的續線直到終局。列依第一次出現排列；已出現的（白、黑）只改寫續線、不搬家。葉子與路徑結尾是黑勝或白勝，不是成功／失敗（成功／失敗仍是對局）。不編號。走完條數不封頂；畫面最多 1000 個（白、黑）葉子。搜尋範圍與最長抵抗不變（ADR-0011、0023）。顯示收束不是搜尋剪枝。

Supersedes the display half of ADR-0019. ADR-0019 still governs unlimited search and emitting 搜尋路徑.
