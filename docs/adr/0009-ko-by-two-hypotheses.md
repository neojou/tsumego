# 劫活／劫殺用贏劫與輸劫两次假設判定

牆上沒有劫材，不能把劫當成對局下完。分類時假設「需要這劫的一方已贏這劫」與「已輸這劫」各得一個終局：一邊能活一邊不能即劫活，一邊能殺一邊不能即劫殺，兩邊都能活即無條件活。殺棋目標仍在、做不成兩眼、且盤上有單劫時是劫殺，不能再落到「做不成兩眼則無條件死」（v1 淨殺才過；打劫失敗）。盤上還沒劫、但白一手能做成單劫且該局面是劫殺（8K 黑 T18 白 S18 黑 T17 後白 T19、黑只能 S19 提劫）也不可當無條件死——那是捷徑錯殺。若目標色仍能往兩眼走，單劫不能把整題凍成劫殺，否則像 7K 白 T19 後黑 R19 提三子這種非劫手段會被搜尋當成白勝葉子。這是搜尋政策，不是眼形模板。
