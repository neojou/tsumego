# v1 只出殺棋題型

v1 解題與出題只針對殺棋（對局標題「黑先殺白」）。做活、雙活題、劫活、劫殺留在詞表，不出現在確認畫面、不寫進新檔、載入時拒絕。沒有做活（等）的 Import 路徑。題目檔仍帶 `goal: kill`，以免後續版本換格式。過／不過仍走 ADR-0003 的殺棋列：成功只認無條件死（提淨或做不成無條件活）；無條件活、雙活、打劫皆失敗。翻色只翻子、題型仍是殺棋，結果是黑先殺白，目標須為白。樣例 v1 列「15K 殺棋」、「13K 殺棋」與「8K 殺棋」（docs/15K-kill.tsumego.json、docs/13K-kill.tsumego.json、docs/8K-kill.tsumego.json）。認圖不能自動判這張圖是做活還是殺棋；沒有做活題型可選。進確認一律殺棋，標白目標即可存（即使原圖是做活譜）。目標不是白就不能確認。不是看圖拒絕進確認畫面。不是把題型欄位從題目拿掉，也不是把「兩眼做活」另立終局。
