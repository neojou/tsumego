# 應手取最長抵抗：黑能強迫的著手數、證明深度、節點數、座標

訓練機在黑仍能強迫成功時，白必須下最難收掉的抵抗，否則同一題每次應手不同、也無法測。主鍵是「黑此刻能強迫成功的著手數」（越少越頑強：黑必須走對，否則白活），再比證明深度（黑最短勝枝還要多少 ply 才能收成「過」），再比是否黑剛下之鄰空（非脫先時：7K 老鼠偷油黑 T16 後是 T15 不是邊上的 Q15；脫先時鄰空不算，small_trick 黑 S15 後是做活點 T16 不是 S14），再比節點數少（證明灌水不是更頑強），再比做活點（兩眼第一手優先），再比座標（檔 A→T，路 1→19，即 A1 < A2 < B1）。只比證明深度會把連回、填氣當成更頑強（small_trick 黑 S19 後選 S18 而不是必須應的 R19）。只比節點多會把 Q15 這種邊上大樹當成比 T15 更頑強。證明深度取黑的最短勝枝，不能用搜尋碰到的第一條勝枝。無法做成無條件活的無條件死也是終局，繼續填氣不加 ply。黑已無法強迫時，反駁手優先做活點（目標色連續落子做成兩眼的第一手，真眼與真盤邊優先）；脫先則白直接下做活點，但必須這手後已 Benson，或黑回來一手殺不掉——不可把「黑永遠脫先、白連填兩眼」當反駁（7K 黑 P18 後白 T18 仍被黑 T15 淨殺；small_trick 黑 S15 後 T16 還差 S17，黑佔 S17 即淨殺，對局繼續不是立刻失敗）。small_trick 黑 S13 後是 S19。
