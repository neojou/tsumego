# 應手取最長抵抗：黑能強迫的著手數、證明深度、節點數、座標

訓練機在黑仍能強迫成功時，白必須下最難收掉的抵抗，否則同一題每次應手不同、也無法測。主鍵是「黑此刻能強迫成功的著手數」（越少越頑強：黑必須走對，否則白活），再比證明深度（黑最短勝枝還要多少 ply 才能收成「過」），再比節點數，再比座標（檔 A→T，路 1→19，即 A1 < A2 < B1）。只比證明深度會把連回、填氣當成更頑強（small_trick 黑 S19 後選 S18 而不是必須應的 R19）。證明深度取黑的最短勝枝，不能用搜尋碰到的第一條勝枝。無法做成無條件活的無條件死也是終局，繼續填氣不加 ply。黑已無法強迫時，反駁手優先做活點（目標色連續落子做成兩眼的第一手，真眼與真盤邊優先）；脫先則白直接下做活點。small_trick 黑 S15 後是 T16 不是 S17，黑 S13 後是 S19。
