# v0.2 檜木盤與蛤碁石：固定微俯視、貼圖當材料、程式補光

v0.1 題目盤是 Compose Canvas 程式畫木紋與扁圓子，明確不是真 3D、不是棋子貼圖。v0.2 只重做呈現：對局／Edit 用淺色檜木盤加蛤碁石（白蛤殼年輪、黑那智黑），固定約 12–18° 俯視，不可旋轉。貼圖用 Grok Image 產無方向光的無縫木紋與單顆石面（albedo）；格線、定向光、厚度、接觸落影、俯視壓扁由程式做。不產帶十九路的整張盤照，以免裁切題對不齊。確認畫面仍原圖當底、正投影子，不扭透視。真盤邊粗黑線、牆虛線加切口暗邊；牆外不是木，盤襯在盤桌上。落子短落再出落子聲，提子短收再出提子聲；音量跟系統，程式不靜音。不是可繞行的 3D 場景，也不是照片自帶光影的 baked 貼圖。
