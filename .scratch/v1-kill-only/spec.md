# v1 只出殺棋

Glossary：`CONTEXT.md`。契約：`docs/adr/0003`、`0014`、`0024`。

## Problem Statement

詞表與程式已有五種題型，但 v1 只想練**殺棋**（標題「黑先殺白」）。確認畫面仍可選做活／雙活／劫，樣例有「角上做活」，題目檔也能開非殺棋，解題者會走進還沒要出的題型。

## Solution

v1 產品只出**殺棋**。出題、存檔、開檔、樣例、對局標題都鎖定殺棋。另外四種題型留在詞表，後續版本再出。過／不過仍走 ADR-0003 的殺棋列。認圖不自動判這張圖是做活還是殺棋；進確認一律殺棋，標白目標即可存。

## User Stories

1. As a 解題者, I want 打開的題都是殺棋, so that v1 不會突然變成做活或雙活題。
2. As a 解題者, I want 對局標題是「黑先殺白」, so that 題型名和標題分得開。
3. As a 解題者, I want 目標無條件死時宣告成功, so that 全滅或白做不成無條件活都算過。
4. As a 解題者, I want 白無條件活時宣告失敗, so that 兩眼做活（Benson）就是沒殺掉。
5. As a 解題者, I want 終局是雙活時殺棋失敗, so that 共氣不算殺死。
6. As a 解題者, I want 終局是打劫（劫活或劫殺）時殺棋失敗, so that 只靠劫不算無條件死。
7. As a 解題者, I want 搜尋尚未證明時看到未定、沒有應手, so that 不會把算不完當過或不過。
8. As a 解題者, I want 打開非殺棋題目檔被拒絕並說明, so that 舊的做活檔不會當成可練的題。
9. As a 解題者, I want File → Samples 只列出殺棋樣例, so that 不會點進角上做活。
10. As a 出題者, I want 確認畫面不選題型、一律殺棋, so that 不會誤存做活。
11. As a 出題者, I want 目標棋串必須是白才能確認, so that 黑先殺白的目標顏色不錯。
12. As a 出題者, I want 選 White First 翻色後仍是殺棋、標題黑先殺白, so that 白先殺黑的譜能變成黑先殺白。
13. As a 出題者, I want 翻色不改目標交叉點、只翻子的顏色, so that 標過的點還在。
14. As a 出題者, I want 翻完若目標變成黑就不能確認, so that 做活譜翻色後不會存成非法殺棋。
15. As a 出題者, I want 拿做活譜進來只要改標白目標就能存成殺棋, so that 認圖不必先猜這張是做活還是殺棋。
16. As a 出題者, I want Edit 打開現有題時也不能改題型, so that v1 改題仍是殺棋。
17. As a 出題者, I want 存檔的題型欄位仍是 kill, so that 後續版本不用換檔格式。
18. As a 解題者, I want Desktop 與 Wasm 對同一殺棋檔行為一致, so that 兩邊都能開、都不能開做活檔。

## Implementation Decisions

- 不刪詞表裡的另外四種題型，不刪終局裡的無條件活／雙活／劫活／劫殺。v1 只是不出那些**題型**。
- **題目庫**：載入時題型必須是殺棋，否則拒絕並說明。寫出的新檔題型是殺棋。非法仍含雙活題單色、做活目標非黑等規則，但 v1 走不到那些題型。
- **確認畫面／Edit**：不提供題型選單；草稿題型固定殺棋。確認約束：目標非空、皆為白。翻色只翻子色，題型仍殺棋。
- **對局**：標題用「黑先殺白」。成功／失敗已由 ADR-0003 殺棋列定義；本 spec 要求迴歸鎖住雙活與打劫皆失敗，不改最長抵抗與做活點。
- **樣例**：v1 列表不含做活樣例；殺棋樣例保留。
- 認圖仍只填子；不從圖判斷題型。
- 解題模組內部仍可分類無條件活／雙活／劫，以便反駁手與失敗。不為 v1 另做「只數兩隻眼空點」的終局。

## Testing Decisions

- 好測試只打外部行為，不鑽分類器內部集合、不對 Compose 截圖像素。
- **題目庫** seam：字面 JSON 往返；`goal` 為 live／seki／koLive／koKill 時拒絕；kill 且目標為白則可開、對局標題為黑先殺白。
- **確認畫面** seam（既有草稿 adapter）：無題型可改；確認時目標必須白；翻色後題型仍殺棋、目標點不變；目標是黑則不能確認；標白後可確認成殺棋。
- **對局** seam：樣例列表沒有做活題名；殺棋題雙活形／只靠劫不能成功（既有或補迴歸）。不新開 seam。

## Out of Scope

- 做活、雙活題、劫活、劫殺作為可玩題型。
- 從棋譜圖自動辨認題型並拒絕進確認畫面。
- 把「兩眼做活」另立終局，或改 Benson。
- 刪除題型欄位或換題目檔格式。
- 改最長抵抗、做活點、相關區搜尋。

## Further Notes

- 實作順序建議：題目庫拒非殺棋 → 確認畫面鎖殺棋 → 樣例與標題迴歸。
- 本 spec 裁的是產品範圍，不是重寫解題器。
