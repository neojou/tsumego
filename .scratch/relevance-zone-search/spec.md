# 相關區搜尋加速

Glossary：`CONTEXT.md`。契約：`docs/adr/0001`–`0023`。核心想法：Shih et al. AAAI 2022（RZS）、2023（pattern table）；分析篇 arXiv:2512.21365。不移植官方 C++ CGI。

## Problem Statement

角題與牆外空兩路之後，解題器在白的每一手抵抗上都要證明黑仍能強迫，搜尋路徑爆炸、思考很久。靜態氣區當硬過濾會漏手或仍太大。需要論文裡的相關區剪枝：事後判定空手、必應區縮小，且不靠神經網、不換最長抵抗。

## Solution

在現有迭代加深 AND-OR 解題裡，由終局自底向上長出 **相關區**。白（AND）證明「黑仍過」後，若這手白在子相關區外，視為 **空手**，其餘區外白手不再搜。黑（OR）證明「無法過」時對偶剪區外黑手。Go 提子／自殺用最小 **dilate** 保住可重放。置換表除整盤外，可用相關區內子形重用局部證明。不移植 CGI／FTL。靜態氣區只當著手順序。

## User Stories

1. As a 解題者, I want 白在遠處的廢棋被當成空手剪掉, so that 證明「黑仍能強迫」不必搜遍牆外空點。
2. As a 解題者, I want 我下在遠離目標棋串時不必把 12 路搜完, so that 失敗／反駁能在戰場內很快出來。
3. As a 解題者, I want 剪枝之後同一手仍是同一應手, so that Desktop 與 Wasm 行為不變。
4. As a 解題者, I want 最長抵抗規則不變, so that 同一局面白不會改下比較好收的點。
5. As a 解題者, I want 搜尋路徑仍列出已走到終局的變化, so that 我看得到算過什麼；區外等價空手不必每手一條。
13. As a 解題者, I want 搜尋路徑不出現白停／黑停, so that 加速不是靠先停，而是靠論文的相關區。
6. As a 解題者, I want 無條件活的相關區含活塊與眼位, so that 白離開眼位的著手被剪。
7. As a 解題者, I want 目標被提淨時相關區含提點與原目標鄰點, so that 殺棋終局也能往上剪。
8. As a 解題者, I want 雙活或劫的終局先不剪相關區, so that 不會把劫材／共氣剪錯。
9. As a 解題者, I want 倒撲與提子後的證明仍正確, so that dilate 不足不會錯判失敗。
10. As a 解題者, I want 區外多一顆無關子時仍能重用局部證明, so that 不必整盤重算同一活形。
11. As a 解題者, I want 小殺棋（例如 B3 應手）迴歸仍過, so that 加速沒改契約。
12. As a 解題者, I want 不依賴 GPU 或第二套解題程式, so that Wasm 也能跑同一套剪枝。

## Implementation Decisions

- 只改 **解題** 模組內部。對局介面、應手選最長抵抗、五種題型、分類順序不變（ADR-0011、0003、0014、0015）。
- 黑是 OR（強迫題型過），白是 AND。證明失敗時對偶：白的擋住／做活帶相關區，剪區外黑手。
- 葉子相關區：無條件活＝Benson 活塊＋其氣／眼位空點；無條件死（提淨）＝原目標點＋鄰點；雙方已停判死＝目標串＋氣＋鄰子；雙活／劫活／劫殺＝整題目盤（不剪）。
- AND：白手得到 Yes 且該點不在子相關區 → 空手，必應區改為與子相關區的交集。OR：黑手得到 No 且在子相關區外 → 同樣縮小必應區。Yes 的相關區＝dilate(子區 ∪ 著手)；AND 證完＝dilate(子區聯集)。
- dilate 最小要涵蓋：著手點、碰到相關區的整串、那些串的氣、一圈鄰點，避免提子／自殺讓區外一手改到區內子形。寧可區大、不可錯剪。
- 停放在候選最後，只為證明「雙方已停則剩餘當死」（死子可留在盤上）。路徑不列含停的變化。空手仍是區外落子。使用者仍可按停。
- 候選手仍由氣區產出並排序；相關區在這份清單上剪空手。把所有合法手都納入會改到最長抵抗（節點數／證明深度），3×3 殺棋應手會從 B3 變成 A3，故本輪不改候選集合。
- 不用蒙地卡羅猜點、不把開局白活點接入每次搜尋。加速只走 RZS。
- 置換：整盤 key。不做 radix-tree 全表掃描（角題會拖死）。區形比對函式留下給測試與下一輪。
- 不移植 `rlglab/study-LD-RZ`／`rockmanray/rzone`（C++、GPL、GPU、MCTS）。

## Testing Decisions

- 好測試打外部行為。主 seam 仍是 **對局**：同一手應手／反駁手不變；遠處等價空手不每手都出現在搜尋路徑。
- 相關區函式（解題內部 seam）：終局局面 → 相關區含已知眼位／活塊的字面座標，不含遠處廢點（例如兩眼形的 B5／D5，不含 A1）。
- 必應區規則：區外著手從剩餘必應裡拿掉；用字面點集合，不當搜尋節點數 tautology。
- 迴歸：3×3 殺棋白仍 B3；提子／倒撲題仍過；small_trick 遠處黑手仍在戰場內被反駁；搜尋路徑不含「停」。
- 不斷言 radix tree、不斷言 Benson 內部集合實作、不對 GPU／官方 CGI 對拍。

## Out of Scope

- 開局黑停找白活點、蒙地卡羅猜點（已有 ADR-0022，本 spec 不依賴它們加速）。
- FTL、神經網、KataGo、官方 C++ 解題器。
- df-pn 當 v1 主搜。
- 用相關區取代最長抵抗。
- 完整 radix-tree pattern 庫、跨題持久 pattern。
- 為劫活／劫殺設計專門相關區（本輪整盤不剪）。
