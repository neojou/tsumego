# 01: 終局相關區與白的事後空手

**What to build:** 終局（無條件活／提淨的無條件死）長出相關區。證明黑仍能強迫時，若白這手在子相關區外，視為空手，其餘區外白手不再搜。3×3 殺棋應手仍是最長抵抗。搜尋路徑不再為每一手等價區外白棋各走一棵樹。

**Blocked by:** None (can start immediately)

**Status:** resolved

- [x] 無條件活的相關區含活塊與眼位，不含遠處廢點
- [x] 白空手之後必應區縮到子相關區內
- [x] 同一手應手／反駁手與剪枝前契約相同（兩眼形 C5；3×3 做不成兩眼則直接成功）
- [x] 區外等價白手不全部出現在搜尋路徑裡

## Answer

終局無條件活的相關區是 Benson 活塊加氣／眼；無條件死是目標點加鄰點／剩餘串加氣。`andMoves` 在白手為空手（點不在子相關區）時用 `retainMustPlay` 把必應區縮到區內。3×3 做不成兩眼則直接成功；兩眼形應手仍是 C5。
