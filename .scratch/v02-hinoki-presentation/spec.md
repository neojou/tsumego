# v0.2 檜木盤與蛤碁石呈現

Glossary：`CONTEXT.md`。契約：`docs/adr/0001`–`0025`（尤其 `0012` 殼與棋盤繪製、`0018` 確認畫面、`0024` v1 只出殺棋、`0025` 本版呈現）。

## Problem Statement

v0.1 已經能練殺棋，但看起來像扁平色圓畫在程式木紋上。About 字級忽大忽小（版本比產品名還搶眼）。盤面不像淺色檜木上的蛤碁石，沒有落子聲，牆外仍像可下的木。解題者打開 15K／13K／8K 時，題目不夠像一盤棋，做題體驗被殼的排版拖累。

## Solution

做 **v0.2 呈現**：對局與 Edit 的題目盤改成固定微俯視的 **檜木盤** 加 **蛤碁石**，襯在 **盤桌** 上；格線與光影仍由程式畫。確認畫面維持原圖當底、正投影蛤碁石。合法落子有 **落子聲**，提子有 **提子聲**。關於與對局左上、搜尋路徑同一套字級。題型仍是殺棋；對局規則、解題、應手、題目檔不變。

## User Stories

1. As a 解題者, I want File → Samples 的 15K／13K／8K 殺棋打開後看到淺色檜木盤上的蛤碁石, so that 題目像一盤棋而不是色圓圖。
2. As a 解題者, I want 白子看得出蛤殼年輪、暖白, so that 不是純白扁平點。
3. As a 解題者, I want 黑子看得出那智黑石的鈍高光, so that 不是純黑圓。
4. As a 解題者, I want 子有厚度、略大於格距, so that 俯視時像坐在盤邊。
5. As a 解題者, I want 光源固定從左上、落影短而貼盤, so that 立體感來自光而不是旋轉鏡頭。
6. As a 解題者, I want 看盤角度固定約 12–18° 俯視且不能拖動旋轉, so that 座標與點擊仍然準。
7. As a 解題者, I want 座標標號畫在螢幕平面上、不跟木紋一起透視變形, so that A–T 與 1–19 仍對得起來。
8. As a 解題者, I want 點交叉點仍然落到正確的點, so that 立體外觀不破壞對局。
9. As a 解題者, I want 真盤邊仍是粗黑線, so that 角題的氣邊分得清。
10. As a 解題者, I want 牆仍是虛線並帶切口暗邊, so that 看得出那是剪開的切口。
11. As a 解題者, I want 牆外不是可下的木面, so that 不會以為可以往圖外逃。
12. As a 解題者, I want 檜木盤浮在盤桌上（淺麻或暗桌）, so that 盤是靜物、桌只是襯。
13. As a 解題者, I want 合法落到空交叉點時聽到落子聲, so that 著手有觸感。
14. As a 解題者, I want 提子時聽到與落子不同的提子聲, so that 吃進盒裡和碰盤分得開。
15. As a 解題者, I want 落子有短落動畫（約 120–180ms）、子碰到盤面時才出落子聲, so that 聲畫同步。
16. As a 解題者, I want 程式的應手與反駁手也用同一套短落與落子聲, so that 白棋不是突然出現。
17. As a 解題者, I want 提子短收（約 100ms）再出提子聲、不飛向碗或畫面外, so that 裁切題不會演一齣飛子。
18. As a 解題者, I want 子碰到盤面之後就能再點、不必等動畫播完, so that 對局節奏不被特效卡住。
19. As a 解題者, I want 接觸前這手已算在盤上, so that 成功／失敗宣告與應手不以動畫結束為準。
20. As a 解題者, I want 悔棋直接還原、不播倒放也不出聲, so that 悔一對是規則不是影片倒帶。
21. As a 解題者, I want 非法手（自殺、佔子、牆外）沒有落子聲也沒有短落, so that 被拒的手不像下成功。
22. As a 解題者, I want 音量跟系統走、程式不做靜音開關, so that 少一塊殼上的控件。
23. As a 解題者, I want Desktop 與 Wasm 同一組落子聲與提子聲, so that 兩邊觸感一致。
24. As a 解題者, I want 剛落下的子面上有一點（白子深點、黑子淺點）, so that 看得出最後一手。
25. As a 解題者, I want 目標棋串每顆子緣有細紅環, so that 厚子不會被大方框切掉球冠。
26. As a 解題者, I want 確認畫面左邊仍列出「目標: A1, B2, …」, so that 標了哪些點不必只靠圖。
27. As a 出題者, I want 確認畫面原圖當底、格線與圖對齊、子是正投影蛤碁石, so that 認圖與對圖擺子不因俯視而錯位。
28. As a 出題者, I want Edit 的木盤模式與對局同一套檜木盤與蛤碁石, so that 改題時看到的就是會拿去練的盤。
29. As a 出題者, I want 確認畫面不要把棋譜圖扭成 12–18° 透視, so that 標目標仍點得到印刷上的子。
30. As a 解題者, I want 打開關於看到產品名「詰碁」最大、一句「圍棋死活訓練機」、版本 v0.2 最小, so that 不再是版本比品名還大。
31. As a 解題者, I want 關於的畫面標題是「關於」而不是 About, so that 和中文殼一致。
32. As a 解題者, I want 選單仍是 Import、File、Edit、About, so that 找得到匯入與樣例。
33. As a 解題者, I want 空畫面提示與左上「黑先殺白／輪黑／思考時間」用同一套字級, so that 殼沒有忽大忽小。
34. As a 解題者, I want 右側搜尋路徑預設打開、紙墨窄欄、同一套字級, so that 思考中仍看得到算過什麼，又不像卡片遊戲。
35. As a 解題者, I want 搜尋路徑仍從 1 編號、可捲動、列出實際條數, so that v0.2 不改對局資訊契約。
36. As a 解題者, I want 格線與座標仍由程式畫在檜木紋上, so that 每題不同大小的題目盤不會對不齊。
37. As a 解題者, I want 木紋可以無縫鋪滿任意矩形題目盤, so that 8K 與 15K 用同一塊材料。
38. As a 解題者, I want 貼圖本身沒有方向光, so that 程式的左上光不會和照片光疊兩次。
39. As a 解題者, I want 成功或失敗時沒有歡呼音, so that 訓練機不像闖關遊戲。
40. As a 解題者, I want 思考中白子未落下時沒有預先動畫, so that 不會在未定時假裝已下。
41. As a 解題者, I want 停沒有落子聲, so that 停不是一顆子碰到盤。
42. As a 解題者, I want Wasm 點交叉點就能出聲（點擊算手勢）, so that 瀏覽器播得出落子聲。
43. As a 解題者, I want v0.2 打開同一道殺棋題、同一手仍是同一應手, so that 美觀不改最長抵抗。
44. As a 解題者, I want 產品版本顯示 v0.2, so that 關於與 v0.1 分得開。

## Implementation Decisions

- 只改殼與棋盤繪製（ADR-0012）。規則、分類、解題、題目庫、認圖行為不變。Desktop 與 Wasm 同一套呈現。
- 對局／Edit 木盤：固定微俯視（約 12–18°）、不可旋轉。座標與目標列表在螢幕平面。點擊命中仍走既有交叉點佈局（中心與 hit），俯視只影響繪製壓扁與陰影，不另做可旋轉相機。
- 材料：Grok Image 產 **albedo**（無方向光）。檜木為可無縫平鋪的淺色直紋；白子、黑子各一張單顆石面（透明底、無baked落影）。不產帶十九路格線的整張盤照。程式負責格線、左上定向光、厚度／唇邊、接觸落影、俯視壓扁。
- 盤桌襯在檜木盤下。牆外＝切口＋暗邊，不是木、不可下。真盤邊粗黑線；牆虛線。
- 確認畫面：棋譜圖當底、正投影蛤碁石（同一套石面、較薄）、不透視。目標環與左邊「目標: …」仍在。
- 最後一手：該子子面一點（白深、黑淺）。目標棋串：子緣細紅環，不再用大方框。
- 落子：短落 120–180ms，接觸瞬間落子聲。提子：短收約 100ms 再提子聲，不飛出畫面。應手／反駁手同一套。悔棋無動畫無聲。非法手無動畫無聲。停無落子聲。成功／失敗無額外音。
- 輸入：接觸盤面後可再點；該手在接觸時已寫進對局，不等動畫結束才算手。
- 音量只走系統；殼上不放靜音。兩邊同一組短音；Wasm 以點擊為手勢。
- 字級一套：產品名「詰碁」最大；一句「圍棋死活訓練機」；版本 `v0.2` 最小、非主色英雄字。關於標題「關於」。TopMenu 仍 Import／File／Edit／About。左上對局標題與輪次、右側搜尋路徑用同一套字。搜尋路徑紙墨窄欄、預設打開、編號與條數契約不變。
- 產品版本常數改為 0.2。樣例仍是 15K、13K、8K 殺棋。

## Testing Decisions

- 好測試只打外部行為。不斷言貼圖像素、不對 Canvas 截圖、不斷言 Grok Image 產圖內容、不斷言音訊波形。
- **盤面佈局**（既有 seam，主 seam）：交叉點 center／hit 在俯視繪製後仍點到同一點；真盤邊粗、牆不粗；目標環是環繞子緣而不是大方框；最後一手標在 `lastMove` 那顆。確認畫面 overlay 的 hit 仍對準印刷子（既有 15K／8K／small_trick 佈局測試要繼續過）。
- **殼文案**（既有 PlayCopy／版本 seam）：關於標題「關於」、產品名「詰碁」、摘要「圍棋死活訓練機」、顯示版本 `v0.2`；空畫面提示與「黑先殺白」等既有文案不因字級改壞。搜尋路徑仍 `1. 白下 B3 -> …`。
- **落子／提子時機**（新、薄 seam）：對局一手的可見結果 → 該出手的是落子聲、提子聲、兩者、或無聲；合法落子伴隨短落、提子伴隨短收；非法手與悔棋與停皆無聲。不斷言分貝或檔名。
- Prior art：`BoardChromeTest`、`BoardLayoutTest`、`OverlayLayoutTest`、樣例圖佈局測試、`PlayCopyTest`、`ShellMenuTest`。目標從方框改環時改既有 chrome 測試，不要另開像素 seam。
- 不新開「貼圖檔是否存在」當正確性測試；缺貼圖時繪製可退回程式色，但不能讓 hit／對局錯。

## Out of Scope

- 新題型、改應手／最長抵抗／相關區搜尋。
- 真 3D 場景、可旋轉鏡頭、Desktop／Wasm 兩套引擎。
- 帶格線的整張 19 路盤照、baked 光影貼圖。
- 確認畫面把棋譜圖扭成俯視。
- 程式內靜音、成功／失敗歡呼、悔棋倒放、提子飛向碗。
- 藏搜尋路徑當預設。
- Android／iOS。
- 實盤照片當 Import 來源（棋譜圖契約不變）。

## Further Notes

- 建議實作順序：字級與關於 → 盤桌／牆外／真盤邊線 → albedo 貼圖鋪木與石 → 俯視壓扁與光 → 目標環與最後一手點 → 短落／短收與兩聲 → 確認畫面正投影子。
- 貼圖產製屬呈現材料，產完放進殼的資源；產圖本身不是對局測試。
- 若 hit 與俯視繪製打架，以 hit 對準交叉點為準，再調繪製，不改規則模組。
