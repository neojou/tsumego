# 03: 檜木無縫紋與蛤碁石貼圖

**What to build:** 對局與 Edit 木盤鋪淺色檜木 albedo、黑白蛤碁石石面。貼圖無方向光；格線與座標仍由程式畫。15K／13K／8K 同一套材料。缺圖可退回程式色，但 hit 與對局不錯。

**Blocked by:** 02: 盤桌、牆外切口、真盤邊線

**Status:** resolved

- [x] 對局／Edit 木盤可見淺色檜木直紋，可鋪滿不同大小的題目盤
- [x] 白子為蛤殼暖白有年輪，黑子為那智黑，不是純色扁圓
- [x] 貼圖本身無方向光；格線與 A–T／1–19 仍程式畫在木紋上
- [x] 不使用帶十九路的整張盤照
- [x] 缺貼圖時繪製可退回程式色，交叉點 hit 與對局結果不變

## Answer

Grok Image 產無方向光檜木無縫紋與單顆黑白石面。木紋平鋪 `woodRect`；子用透明底貼圖，缺圖退回程式漸層。格線仍程式畫。
